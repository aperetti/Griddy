# User Interface

Griddy provides a modern, responsive web interface designed for rapid geospatial exploration and deep analytical dive-ins.

---

## 1. Global Search

The **Global Search** bar (located at the top-left of the map) allows you to instantly locate assets across every loaded CIM model.

- **Fuzzy Matching**: Search by asset name or mRID.
- **Auto-Zoom**: Clicking a search result will automatically center and zoom the map to that asset.
- **Topological Highlighting**: Selecting an asset via search highlights its position in the grid, making it easy to identify its electrical context.

## 2. Dynamic Sidebar

The main navigation sidebar has been redesigned for a smoother user experience:
- **Hover-to-Expand**: The sidebar remains collapsed by default to maximize map real estate and automatically expands when hovered.
- **Instant Switching**: Quickly switch between the main map, the **Admin Console**, and the **Documentation**.
- **Responsive States**: On smaller viewports, the sidebar intelligently adapts to ensure critical navigation remains accessible.

## 3. Analysis Windows

Griddy uses a floating window system for all analytical tools (Consumption, Voltage, etc.).
- **Multi-Window Support**: Run multiple analyses simultaneously for side-by-side comparison.
- **Persistence**: Windows remember their size and position across sessions.
- **Minimized Tray**: Minimize active windows to the tray at the bottom of the screen to keep the workspace tidy without losing your progress.

## 4. Layers Panel

Toggle visibility and styling for various grid components.
- **Model Toggles**: Enable or disable specific CIM models/feeders.
- **Visualization Modes**: Switch between standard map views, satellite imagery, and analytical heatmaps (e.g. Voltage Heatmap).
