# Griddy: Grid-Scale AMI Analytics

:::warning Alpha Project
**Griddy is currently in Alpha (v0.2.7-alpha).**  
This project is under active development. We frequently introduce **breaking changes** to the database schema, API contracts, and grid model structure. There is currently **no guarantee of stability** or backward compatibility.
:::

## Overview

Griddy is an interactive, full-stack application for analyzing electrical distribution grids. It provides engineers and operators with a rich geospatial dashboard for voltage analysis, phase balancing, load-flow tracing, and alarm correlation.

### Key Capabilities

*   **Geospatial Visualization**: Navigate large-scale (12,000+ node) IEEE distribution models.
*   **Graph Traversal**: Trace upstream/downstream connectivity throughout the grid.
*   **Analytics Engine**: Perform statistical voltage distribution and phase balance analysis.
*   **Natural Language interface**: Query grid data using plain English (Powered by SQL-generation agents).

## Roadmap

We are currently focused on improving the display configuration rules and optimizing the graph engine for even larger models. See [Release Updates](./releases.md) for the latest changes.
